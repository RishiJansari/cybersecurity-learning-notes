# Dual Boot & Disk Management Notes

The study material covered a basic dual-boot setup involving Windows, UEFI, Secure Boot and unallocated disk space.

## Basic process
1. Download the OS ISO.
2. Create a bootable USB using a tool such as Rufus, Ventoy or BalenaEtcher.
3. Boot from the USB using the boot menu.
4. Choose an installation option or select/create partitions manually.
5. Install the OS in the intended space.

## Disk management
The notes covered viewing, creating, deleting, formatting and resizing partitions.

Partitioning is also relevant to dual-boot and recovery/data layouts.

> These are study notes from a learning exercise. Partition changes can cause data loss, so backups are important before making changes.
