# Linux Command-Line Basics

## Navigation

```bash
pwd                 # current directory
ls                  # list directory contents
mkdir my_folder     # create a directory
cd my_folder        # enter a directory
cd ..               # go one level up
cd                  # return to home directory
```

## Files and directories

```bash
touch notes.txt     # create a blank file
rm notes.txt        # remove a file
rmdir my_folder     # remove an empty directory
nano script.sh      # edit a file in Nano
```

These commands were part of my basic command-line practice.
