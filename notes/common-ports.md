# Common Network & Service Ports

| Protocol / Service | Port | Purpose / notes |
|---|---:|---|
| HTTP | 80 | Web communication |
| HTTPS | 443 | Encrypted web communication |
| HTTPS (alternative) | 8443 | Alternative/custom HTTPS service |
| HTTP proxy | 8080 | Common proxy/web service port |
| HTTPS proxy | 3128 | Common proxy service port |
| FTP | 21 | File transfer |
| SMB | 139 / 145* | Network file/folder sharing |
| SSH | 22 | Secure remote shell/access |
| Telnet | 23 | Remote login |
| RDP | 3389 | Remote desktop access |
| SMTP | 25 | Sending/relaying email |
| POP3 | 110 | Receiving email |
| IMAP | 143 | Email access/synchronization |
| DNS | 53 | Domain-name resolution |
| NTP | 123 | Network time synchronization |
| SNMP | 161 | Network device management/monitoring |
| LDAP | 389 | Directory services |
| MySQL | 3306 | Database service |
| Microsoft SQL Server | 1433 | Microsoft database service |
| Oracle Database | 1521 | Oracle database connectivity |

`*` The original study notes list SMB as `139, 145`; this entry should be verified before treating it as a technical reference.

SQL = Structured Query Language.
