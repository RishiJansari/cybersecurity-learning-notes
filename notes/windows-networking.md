# Windows Networking & Troubleshooting

## Device Manager
Windows Device Manager can be used to view hardware devices and their drivers.

Basic process from my notes:
1. Open Device Manager.
2. Find the relevant category, such as Network adapters.
3. Open Properties.
4. Check Device status.
5. Look for warning indicators.
6. If needed, update or reinstall the driver.

## Common network problems
The notes cover:
- Connection drops
- DNS/name-resolution issues
- Packet loss
- IP address conflicts
- Network configuration errors

A basic starting point is to test connectivity with `ping`.

```text
ping google.com
ping 192.168.1.1
```
